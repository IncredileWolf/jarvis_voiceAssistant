# Jarvis Voice Assistant

A modular AI-powered desktop assistant built using Python.

## Features

- Voice Recognition
- AI using Ollama
- Browser Automation
- Desktop Automation
- Google Search
- Conversation Memory
- Configurable Commands

## Tech Stack

- Python 3.12
- Ollama
- SpeechRecognition
- PyAudio
- Requests

## Project Structure

```
ai/
commands/
core/
data/
memory/
prompts/
```

## Run

Create virtual environment

```bash
python -m venv venv312
```

Activate

Windows

```bash
venv312\Scripts\activate
```

Install packages

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
